# EHR Admission Workflow Improvement

## Project Overview

This clinical informatics project evaluates a fictional EHR admission documentation workflow that has increased nursing documentation time following implementation. The project demonstrates the use of workflow analysis, stakeholder feedback, clinical reasoning, and measurable outcomes to identify opportunities for EHR optimization.

All information used in this project is fictional and contains no protected health information (PHI).

## Problem Statement

A newly implemented EHR admission documentation workflow has increased the average time nurses spend completing admission documentation from approximately 18 minutes to 31 minutes. Although documentation completion rates have remained relatively unchanged, the increased documentation time may reduce the time nurses have available for direct patient care and contribute to workflow inefficiency.

Because admission documentation contains important clinical information, the goal of this project is to identify factors contributing to the increased documentation time and determine whether workflow changes can improve efficiency while maintaining documentation quality and patient safety.

## Current-State Assessment

Ten admission documentation workflows were observed to identify potential sources of inefficiency.

| Measure | Observation |
|---|---|
| Previous average completion time | 18 minutes |
| Current average completion time | 31 minutes |
| Average screens visited | 14 |
| Average times nurse leaves admission workflow | 6 |
| Average duplicate documentation events | 5 |
| Longest workflow section | Medication reconciliation, 9 minutes |
| Required fields completed | 96% |

Observation and nursing feedback suggested that the increased completion time was related to workflow design rather than a simple lack of staff knowledge.

## Current-State Workflow

1. Patient is admitted to the unit.
2. Nurse opens the EHR admission documentation workflow.
3. Nurse begins the admission assessment.
4. Nurse navigates through multiple documentation screens.
5. Nurse encounters medication reconciliation requirements.
6. Nurse leaves the admission workflow to review information from the home medication list, previous encounters, pharmacy history, and provider documentation.
7. Nurse returns to the admission workflow and enters medication information.
8. Some information is documented in multiple locations.
9. Nurse continues through the remaining admission documentation.
10. Nurse reviews required fields and completes the admission workflow.

## Identified Workflow Concerns

The assessment identified several potential contributors to increased documentation time:

- Repeated navigation between multiple EHR screens.
- Duplicate documentation requirements.
- Medication reconciliation interrupting the natural flow of the nursing admission assessment.
- Nurses leaving and returning to the admission workflow multiple times to retrieve information.
- Increased documentation burden without a meaningful improvement in overall completion.

These findings suggest that workflow optimization should be evaluated before assuming additional staff training alone will resolve the problem.

## Proposed Future-State Workflow

The proposed workflow would separate the initial nursing admission assessment from portions of medication reconciliation that do not need to be completed immediately.

1. Patient is admitted to the unit.
2. Nurse opens the admission documentation workflow.
3. Nurse completes the initial nursing assessment.
4. Essential medication and safety information required for immediate patient care is documented.
5. Nurse completes the remaining admission documentation without unnecessary interruption.
6. Full medication reconciliation is completed through a dedicated workflow within the organization's required timeframe.
7. Pharmacy and other appropriate disciplines can review medication information as needed.

Before implementation, nursing, pharmacy, providers, EHR analysts, and organizational leadership would determine which medication information must remain part of the initial admission process for patient safety, regulatory compliance, and continuity of care.

## 30-Day Pilot Plan

The redesigned workflow would initially be piloted on one medical unit for 30 days rather than implemented hospital-wide.

Prior to implementation, participating nurses would receive education on the redesigned workflow and expectations for completing medication reconciliation.

During the pilot, workflow data would be collected and compared with baseline measurements.

### Evaluation Measures

The pilot would evaluate:

- Average admission documentation completion time.
- Percentage of admission documentation completed within the required timeframe.
- Documentation errors, missing fields, and corrections.
- Percentage of required medication information documented within the appropriate timeframe.
- Percentage of full medication reconciliations completed on time.
- Medication discrepancies or delays potentially associated with the redesigned process.
- Nursing feedback regarding workflow usability.
- Pharmacy feedback regarding the timeliness and completeness of medication information.

## Expected Outcome

The goal of the proposed redesign is to reduce unnecessary documentation burden and improve nursing workflow efficiency without compromising documentation completeness, medication safety, or patient care.

Success would not be determined by documentation time alone. A successful pilot would demonstrate improved efficiency while maintaining or improving documentation quality, medication reconciliation compliance, and patient safety measures.

## Limitations and Considerations

This project represents a fictional workflow improvement scenario and does not demonstrate the effectiveness of an actual EHR modification.

Workflow changes should not be implemented based solely on nursing documentation time. Medication reconciliation requirements, regulatory standards, patient safety considerations, organizational policies, and the needs of other disciplines must also be considered.

Additional factors such as nurse experience, patient acuity, admission type, interruptions, and differences between hospital units could affect documentation time and should be considered when evaluating pilot results.
